# Sales Performance Dashboard – Power BI

## 📊 Project Overview
An interactive Power BI dashboard designed to analyze sales performance and present key business insights through KPIs, charts, and interactive filters.

## 📌 Dashboard Features
- Total Revenue
- Total Orders
- Average Price
- Average Quantity
- Yearly Revenue Trend
- Revenue by Product Category
- Revenue by Country
- Order Status Distribution
- Quantity vs Revenue
- Interactive Category, Country, and Order Status filters

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
- Python
- Pandas

## 🎯 Objective
To transform sales data into an interactive and easy-to-understand dashboard that helps identify important sales patterns and performance trends.
